## 💡 Project Overview

**QuickPlate** is a meal delivery mobile app concept.

| | |
|---|---|
| **Problem** | Busy people struggle to find and order healthy meals quickly because of long menus and confusing checkouts. |
| **Goal** | Let a user order a meal in **under 2 minutes**. |
| **Platform** | Mobile (iPhone 14 Plus frame, 428 × 926) |

### Design process

```
 Task 1            Task 2                  Task 3
```

## ✅ Task 2 — Wireframing & User Journey Mapping

**Objective:** Define the app concept, understand the users, and design low-fidelity wireframes for the main ordering flow.

### 👥 User Personas

| | **Ayesha, 24** 🎓 University Student | **Hamza, 35** 💼 Office Professional |
|---|---|---|
| **Goal** | Order cheap meals quickly between classes | Get a healthy lunch delivered at work |
| **Needs** | Deals, fast reordering, low delivery fees | Diet filters, scheduled delivery, live tracking |
| **Frustrations** | Hidden charges, slow checkout, too many steps | Late deliveries, unclear menus, no healthy options |
| **Tech comfort** | High | Medium |

### 🔀 User Flows

**Main flow: ordering a meal**

![Main user flow](assets/task2/user-flow.png)

**Secondary flow: finding a meal with filters**

`Home → Search → Filter (diet, price) → Restaurant Menu → Cart`

### 🗺️ User Journey Map (Ayesha ordering lunch)

| Stage | Action | Feeling | Pain point → Opportunity |
|---|---|---|---|
| **Discover** | Opens app, browses Home | 😋 Hungry, hopeful | Too many options → *Show popular meals first* |
| **Choose** | Opens menu, picks an item | 🤔 Curious | Unclear prices → *Show price clearly* |
| **Order** | Adds to cart, checks out | 😬 Impatient | Slow checkout → *Keep it to 3 taps* |
| **Wait** | Tracks the order | 😟 Anxious | No updates → *Show live progress* |
| **Receive** | Gets food, rates order | 😊 Satisfied | → *Make reordering one tap* |

### 🧭 Screen List & Navigation

| # | Screen | Key elements | Navigates to |
|---|---|---|---|
| 1 | **Login / Sign up** | Logo, email/phone, password, Login button, Sign up link, Google login | Home |
| 2 | **Home** | Location bar, search, category chips, popular meals, bottom menu | Restaurant Menu, Search, Profile |
| 3 | **Restaurant Menu** | Back arrow, banner, rating and delivery time, items with [+], View Cart | Item Detail, Cart |
| 4 | **Item Detail** | Large image, name, description, price, quantity selector, Add to Cart | Cart |
| 5 | **Cart** | Items, promo code, subtotal, delivery fee, total, Checkout | Checkout |
| 6 | **Checkout** | Address, payment method, order summary, Place Order | Order Tracking |
| 7 | **Order Tracking** | Map, progress steps, rider info with call button | Home, Rate Order |

## ✅ Task 3 — High-Fidelity UI Component System

**Objective:** Scale the Task 2 wireframes into polished, interactive, high-fidelity screens backed by a consistent design system.

### 🔤 Typography System

A single type family with a clear hierarchy:

| Style | Size | Weight |
|---|---|---|
| **H1 / Screen Title** | 24px | Semibold |
| **H2 / Section Title** | 18px | Semibold |
| **Body** | 14px | Regular |
| **Caption / Helper Text** | 12px | Regular |
| **Button Label** | 14px | Medium, all-caps, +0.5px tracking |

### 🎨 Design Tokens

**Color tokens**

| Token | Usage |
|---|---|
| **Primary** | Primary buttons, active states |
| **Secondary** | Secondary actions, highlights |
| **Surface / Background** | Screens and cards |
| **Text Primary / Secondary** | Main and muted text |
| **Success / Warning / Error** | Status and feedback (e.g. order tracking) |

**Spacing & sizing tokens**

| Token | Value |
|---|---|
| **Base spacing scale** | 4 / 8 / 12 / 16 / 24 / 32 px |
| **Corner radius** | 8px (inputs, buttons) · 16px (cards) |
| **Touch target minimum** | 44 × 44 px |

### 🧩 Interactive Components

| Component | States | Used in |
|---|---|---|
| **Buttons** | Primary, secondary, disabled (with hover/press styles) | All screens |
| **Input fields** | Default, focused, filled, error | Login, search, checkout |
| **Dropdown menus** | Open, selected | Diet/price filters, quantity selection |

### 📲 High-Fidelity Screens

All seven wireframe screens were converted: **Login · Home · Restaurant Menu · Item Detail · Cart · Checkout · Order Tracking**

### ♿ Accessibility (WCAG 2.1)

- ✅ **4.5 : 1** minimum contrast for normal body text
- ✅ **3 : 1** minimum contrast for large text and UI components
- ✅ **44 × 44 px** touch targets for every interactive element
